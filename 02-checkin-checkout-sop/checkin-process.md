# Check‑In Process SOP

## 1. Pre‑Arrival Confirmation
- Confirm ETA 24 hours before arrival.
- Re-send arrival instructions if needed.
- Ensure cleaning is completed and property is ready.

## 2. Sending Check‑In Instructions
- Address + navigation steps.
- Entrance photo.
- Keybox code or meeting point.
- WiFi details (if applicable).
- Contact channel for support (WhatsApp/Viber).

## 3. Real‑Time Availability
- Be available 1 hour before and after ETA.
- Monitor guest messages in PMS/WhatsApp.

## 4. Arrival Verification
- Send “arrival check” message 30 minutes after ETA.
- Confirm access was successful.
- Log check‑in status in PMS.

## 5. Issue Handling
- If access fails, follow Issue Resolution Workflow.
- Provide alternative instructions if needed.
- Notify maintenance/cleaning if required.
